# video-telop（Claude向けメモ）

- 依頼者は日本語教師。プログラミングに詳しくないので、具体例つきの日本語で説明し、こまめに意図を確認する。
- テロップの判断は必ず [テロップルール.md](テロップルール.md) に従う。新しいルールを教わったら、このファイルに追記する。
- 手順とコマンドは [README.md](README.md)。新しいセッションでは最初に `./setup.sh` を実行する。
- 文字起こしは聞き間違いがあるので、台本を書くときに文脈で直す（例：「前日運休」→「全日運休」）。
- 送れるファイルは30MBまで。依頼者は動画を分割して送ってくる → `tools/join_parts.py` でつなげてから作業する。無言カットは依頼者が自分でやる（カット後の動画を送ってもらう）。
- Whisperの作文に注意：「1.」「2.」などの番号、最後の「ご視聴ありがとうございました」、同じ言葉の繰り返し。怪しい所は区間だけ `condition_on_previous_text=False` で文字起こしし直し、映像（指の数など）も見て判断する。
- 動画・音声・フォントはコミットしない（.gitignore済み）。
- CapCut確認済み：SRTは読み込める。SRTに色の指定（<font color>）を書いても色は出ない。ASS形式は読み込めない。→ 色・フォント・箱は依頼者がCapCutで種類ごとに設定する（プリセット保存をすすめる）。
- 未確認：ふりがなSRT（全角スペースで位置合わせ）がずれないか。
